# Dataset Setup
The dataset is not included in this repository. To train the model, download and unzip it inside the `obstacle-detection` folder:

```bash
curl -L "https://app.roboflow.com/ds/grk91iJX3K?key=Nioy375aY6" > roboflow.zip
# Unzip directly into a folder named 'dataset'
unzip roboflow.zip -d ./dataset/
rm roboflow.zip
```
